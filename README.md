# ONG Mãos Unidas

Projeto acadêmico de desenvolvimento front-end com HTML5 semântico, CSS responsivo, JavaScript para máscaras e formulário de voluntariado.

## Estrutura
- `index.html`: página inicial institucional.
- `projetos.html`: projetos e formas de participação.
- `cadastro.html`: formulário de voluntariado.
- `css/styles.css`: estilos globais.
- `js/masks.js`: máscaras de CPF, telefone e CEP.
- `img/`: assets em SVG, PNG, JPG e WebP.

## Assets
As imagens raster possuem versões WebP otimizadas e versões tradicionais como fallback. O HTML utiliza `<picture>` e `<source>` para priorizar WebP.

## Acessibilidade
Foram utilizados `alt`, `figcaption`, hierarquia de títulos, `label` associado aos campos, `fieldset`/`legend` e navegação semântica.

## Validação
O projeto foi preparado seguindo boas práticas HTML5. A validação final no W3C deve ser executada com os arquivos reais hospedados ou enviados ao Nu HTML Checker/Markup Validation Service.
